Sito per un'hamburgeria di Modena (dal 2016): manzo 100% italiano da allevamento brado cotto sulla brace di faggio e pane lievitato in casa. Hero cinematico, menù, racconto della materia prima e prenotazione del tavolo.

*Website for a Modena burger joint (since 2016): 100% Italian grass-fed beef charcoal-grilled over beechwood, house-leavened bread. Cinematic hero, menu, sourcing story and table booking.*

**Stack:** next, react, tailwindcss

## Avvio in locale · Run locally

```bash
npm install
npm run dev
```

Poi apri / then open http://localhost:3000
